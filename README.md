# الميزان الحديث | Al-Mizan Al-Hadith Islamic Research Center

Official global web portal for **Al-Mizan Al-Hadith (المیزان الحدیث)** Islamic Research Center and the complete scholarly library of **Researcher Abu Muhammad Khurram Shahzad (أبو محمد خرم شہزاد)**.

## Key Features
- **Interactive Hadith & Isnad Verification Workbench (`دار التخريج والعلل`)**: Live multilingual search across Arabic, Urdu, and English with graded Hukm badges and unbroken Sanad chain visualization.
- **Scholarly Library of Abu Muhammad Khurram Shahzad**: Dedicated wing showcasing 6 encyclopedic monographs with interactive chapter readers, Arabic/English manuscript excerpts, one-click academic citations, and downloadable monograph dossiers.
- **Trilingual Interface (English / اردو / عربي)**: Instant language and RTL/LTR switching with authentic `Amiri` and `Noto Nastaliq Urdu` typography.
- **Illuminated Manuscript & Samarqand Parchment Themes**: Dual scholarly reading modes.

## Deploying to GitHub & Vercel (`zeroai903@gmail.com`)

### Option A: Zero-Terminal Web Upload (Fastest — 2 Minutes)
1. Sign in to [github.com](https://github.com) with **`zeroai903@gmail.com`**.
2. Click **New Repository** → Name it `al-mizan-al-hadith` → Click **Create repository**.
3. Click **uploading an existing file** on the repository setup page.
4. Drag and drop all files from `C:\Users\as\Documents\al-mizan-al-hadith`:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `vercel.json`
   - `README.md`
5. Click **Commit changes**.
6. Go to [vercel.com](https://vercel.com) → Click **Continue with GitHub** → Click **Add New Project** → **Import** `al-mizan-al-hadith` → Click **Deploy**.
   - Your website will be live globally on `https://al-mizan-al-hadith.vercel.app` in ~15 seconds!
